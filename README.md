# PyFlink Example — Message Validation and Kafka

A small **PyFlink DataStream API** example demonstrating how to read messages from a collection, validate them, and send only valid messages to a Kafka topic.

## Overview

The application implements a simple streaming pipeline:

```text
Collection
    │
    ▼
  Parse
    │
    ▼
Validate email
    │
    ├── Invalid ──► Discard
    │
    ▼
 Valid message
    │
    ▼
  Kafka
```

Each input message represents a user:

```text
1,Alice,a@a.com
```

The application converts the message into a `User` object:

```text
User(id='1', name='Alice', email='a@a.com')
```

A message is considered valid when the email address contains an `@` character.

Only valid messages are sent to Kafka.

## Example

### Input

The application receives messages from a collection:

```text
1,Alice,a@a.com
2,Bob,bexample.com
3,Charlie,c@c.com
```

### Validation

The messages are converted to `User` objects and validated:

```text
1,Alice,a@a.com       → Valid
2,Bob,bexample.com    → Invalid
3,Charlie,c@c.com     → Valid
```

### Kafka output

Only the valid messages are sent to Kafka:

```text
1,Alice,a@a.com
3,Charlie,c@c.com
```

## Requirements

* Python 3.10+
* Java >=11
* `uv` (recommended)
* PyFlink 1.20

## Installation

Clone the project and install the dependencies with `uv`:

```bash
pip install uv
uv lock
uv sync
```

The project dependencies are declared in `pyproject.toml`, while `uv.lock` generated by the previous commands contains the resolved versions.

You can check the installed PyFlink version with:

```bash
uv run python -c "import pyflink; print(pyflink.__version__)"
```

## Running the Example

Run the application with:

```bash
uv run python -m pyflink_example.main
```

Alternatively, if your environment is already activated:

```bash
python -m pyflink_example.main
```

The Flink job creates a streaming pipeline and executes it locally.

## Using dockerfile to run the job

### 1. Build the Docker Image
From the root of the project, where the Dockerfile is located (uncomment line 36 first):

```text
docker build -t my-pyflink:1.0 .
```
Verify that the image was created:
```text
docker images
```
### 2. Run the Application

The Docker image is configured to start the PyFlink application automatically:
```text
docker run --rm -it my-pyflink:1.0
```
The **`--rm`** option automatically removes the container when it exits.

The **`--it`** options make the container interactive and display the application output directly in the terminal.
